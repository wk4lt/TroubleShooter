# SQL 查询与优化规范

## 编写规范

- 关键字大写,表名/列名统一风格,长查询合理换行与缩进。
- 显式列出需要的列,避免 `SELECT *`。
- 使用参数化查询,禁止字符串拼接用户输入。
- 明确写出 JOIN 条件与 WHERE 过滤,避免隐式笛卡尔积。

## 优化要点

1. **索引**:WHERE / JOIN / ORDER BY 涉及的列是否命中索引,避免在索引列上使用函数。
2. **分页**:大表分页优先使用游标/`WHERE id > ?` 而非超大 `OFFSET`。
3. **避免**:`SELECT DISTINCT` 滥用、`OR` 导致全表扫、`LIKE '%x%'` 无法走索引。
4. **关联子查询** 改写成 JOIN 或窗口函数。
5. **大数据量** 分批处理,避免一次性加载到内存。

## 输出格式

先给出改写后的 SQL,再用表格列出「问题 → 原因 → 优化建议」。不确定表结构时明确标注假设。
